# Starbucks Coffee Website

This is a simple Starbucks coffee website made with **HTML, CSS, and JavaScript**.  
It has sections for:
- Shopping for Starbucks products
- Delivery with Uber Eats
- Download the App
- 50 Years of Serving Communities

## How to Open
1. Download or clone the project.
2. Open the `index.html` file in your browser.

## Features
- Responsive design for mobile and desktop.
- Modern UI layout.
- JavaScript for interactive elements.
- Shopping section to browse and view products.

## Technologies Used
- HTML5
- CSS3
- JavaScript
